# Mesh BMW X5

Здесь должны находиться:
- `bmw_x5.x` — модель после экспорта в формат, поддерживаемый редактором оригинального MudRunner;
- `bmw_x5.xml` — mesh XML, созданный/настроенный в MudRunner Editor.

Не добавляйте фиктивные MeshParts: названия частей должны совпадать с реальными кадрами
экспортированной модели.
