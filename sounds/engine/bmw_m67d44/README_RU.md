# Звуки BMW X5 E53 — дизельный V8 свап

Пакет звуков для проекта оригинального **Spintires: MudRunner**.

## Выбранный двигатель

Для игрового свапа выбран BMW M67D44 — дизельный V8 объёмом 4,4 л с двумя турбинами. Это не заводской двигатель X5 E53: M67 применялся в BMW 7 Series (740d/745d). Для нашей машины это намеренная нестандартная конфигурация.

## Что уже создано

Генератор `tools/generate_diesel_v8_sounds.py` создаёт 8 оригинальных процедурно синтезированных WAV-файлов:

| Событие | Файл | Длительность |
|---|---|---:|
| Запуск двигателя | `bmw_m67d44_start.wav` | 3,4 с |
| Остановка двигателя | `bmw_m67d44_stop.wav` | 2,2 с |
| Холостой ход | `bmw_m67d44_idle.wav` | 8 с |
| Низкие обороты / нагрузка | `bmw_m67d44_low.wav` | 8 с |
| Разгон | `bmw_m67d44_accel.wav` | 7 с |
| Высокие обороты | `bmw_m67d44_high.wav` | 8 с |
| Турбина | `bmw_m67d44_turbo.wav` | 5 с |
| Переключение передач | `bmw_m67d44_gear.wav` | 0,55 с |

Формат всех файлов: WAV PCM, mono, 44 100 Hz, 16-bit. Это синтезированные звуковые заготовки, не реальные записи двигателя и пока не акустически достоверная запись M67D44.

## Сборка и проверка

GitHub Actions workflow `.github/workflows/build-sound-pack.yml`:
1. генерирует WAV-файлы;
2. проверяет наличие всех восьми файлов, формат, частоту и длительность через `tools/validate_diesel_v8_sounds.py`;
3. собирает ZIP-артефакт `bmw-x5-m67d44-sound-pack`.

## Статус подключения к игре

**Звуки пока не подключены к классу BMW X5.** В репозитории ещё нет проверенного `classes/trucks/bmw_x5.xml`.

Не добавлять секцию `<Sounds>` наугад: сначала нужен исходный truck-class XML оригинального MudRunner, созданный/сохранённый через MudRunner Editor, чтобы подтвердить точные имена звуковых событий и правила адресации WAV в этой версии игры. Схему SnowRunner использовать нельзя — это другой формат/поколение игры.

Для завершения интеграции требуется:
1. создать базовый truck class в MudRunner Editor;
2. получить его XML из оригинального MudRunner;
3. проверить формат и путь хотя бы одного WAV на штатном примере;
4. прописать восемь звуковых событий в подтверждённой схеме;
5. открыть класс в Editor и проверить звук запуска, холостого хода, нагрузки, сброса газа и переключения передач в самой игре.

Папка `sounds/engine/bmw_m67d44` в исходниках содержит документацию; сами WAV выдаются отдельным ZIP-артефактом CI.
