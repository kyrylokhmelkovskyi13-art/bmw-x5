# Звуки BMW X5 E53 — дизельный V8 свап

План звукового пакета для оригинального Spintires: MudRunner.

## Выбранный двигатель

Для игрового свапа выбран BMW M67D44: дизельный V8 объёмом 4,4 л с двумя турбинами. Это не заводской двигатель X5 E53: M67 применялся в BMW 7 Series (740d/745d). Для нашей машины это намеренная нестандартная конфигурация.

## Нужные звуковые события

| Событие | Файл-план |
|---|---|
| Запуск двигателя | `sounds/engine/bmw_m67d44_start.wav` |
| Остановка двигателя | `sounds/engine/bmw_m67d44_stop.wav` |
| Холостой ход | `sounds/engine/bmw_m67d44_idle.wav` |
| Низкие обороты / нагрузка | `sounds/engine/bmw_m67d44_low.wav` |
| Разгон | `sounds/engine/bmw_m67d44_accel.wav` |
| Высокие обороты | `sounds/engine/bmw_m67d44_high.wav` |
| Турбонаддув | `sounds/engine/bmw_m67d44_turbo.wav` |
| Переключение передач | `sounds/engine/bmw_m67d44_gear.wav` |

## Важный статус

Это спецификация, а не готовые аудиозаписи. В репозитории пока нет проверенных WAV-файлов, поэтому пустые или синтетические заглушки не выдаются за реальные звуки двигателя.

Перед подключением необходимо:
1. Получить аудиозаписи с разрешением на использование/распространение.
2. Проверить частоту дискретизации, каналы и формат на примере звуков оригинального MudRunner.
3. Взять структуру секции `<Sounds>` из truck XML оригинального MudRunner и привязать имена событий к реальным путям.
4. Проверить запуск, холостой ход, разгон, сброс газа и звук из кабины в MudRunner Editor/игре.

Не копировать XML-схему SnowRunner: проект рассчитан на оригинальный MudRunner.
