# Truck class BMW X5

Файл `bmw_x5.xml` нужно создать через MudRunner Editor после подготовки mesh.

Обязательные привязки, которые нужно назначить по реальной иерархии модели:
- mesh кузова;
- физические кадры кузова/шасси;
- четыре wheel frame и их ParentFrame;
- параметры двигателя, коробки, подвески и массы.

Не используйте случайные имена кадров и значения из шаблонов для другой машины.
Пока class XML не создан и не проверен в MudRunner Editor, мод не готов к игре.
